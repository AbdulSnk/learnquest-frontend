# LearnQuest Frontend

## Project Overview
LearnQuest is a micro-learning platform where users learn in small units, contribute knowledge, and track their progress and impact in a gamified way.  

This repository contains the **frontend** built with **Vite + React + TypeScript + Tailwind CSS**.

---

## Getting Started

### Prerequisites
- Node.js >= 22
- npm >= 10

### Installation
```bash
git clone https://github.com/<your-username>/learnquest-frontend.git
cd learnquest-frontend
npm install
npm run dev

Open http://localhost:5173/ in your browser
